# API tài khoản thanh toán

## Lấy danh sách tài khoản thanh toán

Lấy thông tin các tài khoản thanh toán của tổ chức được xác định bởi API key. Dữ liệu được lọc theo chế độ `TEST_MODE` hoặc `LIVE_MODE` của key và sắp xếp theo `id` tăng dần.

Endpoint này không yêu cầu `X-Signature`. Xem [API Keys](/developers/api-key) để cấu hình xác thực.

##### Request Parameters

Không có path parameter, query parameter hoặc request body. Không cần gửi ID tổ chức hay mode; hệ thống lấy từ API key. Endpoint không phân trang.
