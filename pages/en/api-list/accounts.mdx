# Payment Accounts API

## List payment accounts

Retrieve payment accounts for the institution identified by the API key. Results are filtered by the key’s `TEST_MODE` or `LIVE_MODE` and sorted by `id` in ascending order.

This endpoint does not require `X-Signature`. See [API Keys](/developers/api-key) for authentication setup.

##### Request Parameters

No path parameters, query parameters or request body are required. Do not send an institution ID or mode; both are determined by the API key. This endpoint is not paginated.

##### Responses

<div className="flex gap-2 items-center py-4">
<div className="flex-1 text-md font-bold">200 OK</div>

The response is a direct `Account[]` array, without a `data` or `items` wrapper. If no accounts match, it returns `[]`. The list includes inactive or blocked accounts; check `status` and `isBlocked` when displaying account state.
