# Return request API



All endpoints require `Authorization: Bearer <secretKey>` and `X-Api-Key: <publicKey>`. Every POST also requires `Content-Type: application/json` and `X-Signature`, calculated from the complete request body using your `checksumKey`. Recalculate the signature whenever the body changes. See [signature generation](/developers/signature). GET requests do not require `X-Signature`. Data is scoped to your institution and the API key’s test/live mode.

<br />

**Return flow**

1. Read the [order details](/api-list/order#get-order-details-api) and select eligible items from a `SUCCESS` order.
2. Create a return with a new `returnTrackId` and explicit `items`.
3. A manual request starts at `REQUESTED`; 
4. Poll the return details or process `RETURN_ORDER_UPDATE` [webhooks](/webhooks#return-request-payload). `REFUNDING` means processing; `COMPLETED` means the return has completed.
5. Refresh order details to obtain cumulative returned quantities, refund amount and remaining total.

**Eligibility**

- Order and selected items must be `SUCCESS`, within 6 months of order creation, and belong to the same institution/mode.
- Only one pending or refunding request may exist for an order at a time. A new request can be created once the previous request has reached the COMPLETED or CANCELED/REJECTED status.
- Exclude quantities and ICCIDs already reserved or returned by requests other than `CANCELED`/`REJECTED`. eSIMs must also have return status `NONE`.
- To return everything, explicitly include all remaining eligible quantities/ICCIDs. The server calculates `FULL` or `PARTIAL` against the remaining eligible units.

<br />

**Fees and processing**

The current base fee is 15,000 VND per returned eSIM or physical SIM; SIM recharge has no base return fee. Each item’s initial refund is `max(unit price × returned quantity − return fee, 0)`. The request sums these amounts; an order with a non-positive total has request-level refund fee and amount set to zero. Review may add `extraFee` with `extraFeeNote`; use the API’s final `refundAmount` for reconciliation.

The example returns one of two eSIMs priced at 100,000 VND each: base fee 15,000 VND, refund 85,000 VND.

## Errors and HTTP status

GET succeeds with HTTP 200; POST currently uses HTTP 201. Validation, duplicate `returnTrackId`, duplicate items, expired/fully returned orders, an existing active request, unavailable quantities/ICCIDs or canceling a non-`REQUESTED` request return 400. A missing or non-`SUCCESS` order and a missing return request return 404.
